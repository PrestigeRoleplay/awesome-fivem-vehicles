# Contributing to Awesome FiveM Vehicles

Thank you for your interest in contributing! This list aims to be a high-quality, curated collection of tools, resources, and guides for FiveM vehicle modding.

## Guidelines

### Adding a Resource

1. **Fork** this repository.
2. **Edit** `README.md` and add your resource to the appropriate section.
3. **Submit** a pull request with a clear description of what you are adding and why.

### Requirements

- The resource must be **directly related** to FiveM vehicles (tools, scripts, guides, assets, etc.).
- The resource must be **actively maintained** or still functional. Abandoned projects with no updates in 2+ years will generally not be accepted.
- Links must point to the **official source** (GitHub repo, official website, or well-known modding platform).
- Descriptions should be **concise** — one sentence that explains what the resource does.
- Follow the existing **formatting style**: `- [Name](URL) - Description.`

### Quality Standards

- Tools and scripts should have a README or documentation.
- Paid resources are acceptable if they provide clear value and are from reputable sources.
- No pirated content, leaked assets, or resources that violate Rockstar's or Cfx.re's terms of service.
- No duplicate entries — check that the resource is not already listed.

### Section Order

Please add new entries at the **end** of the relevant section, unless alphabetical ordering is already in use.

### Reporting Issues

If you find a broken link, outdated resource, or have a suggestion, please [open an issue](https://github.com/PrestigeRoleplay/awesome-fivem-vehicles/issues).

## Code of Conduct

Be respectful and constructive. This is a community resource — keep it welcoming for everyone.
